# Contributing to Micromet

Thank you for your interest in contributing to **Micromet**, a project by **DotMote Labs** that brings real-time, fine-scale environmental monitoring to the field. Whether you're fixing bugs, improving documentation, or building new features — we welcome your input!

## 🛠️ How to Contribute

### 1. Fork the Repository
Create your own copy by clicking **“Fork”** in the upper right corner of the repository.

### 2. Clone Your Fork
```bash
git clone https://github.com/your-username/micromet.git
cd micromet
